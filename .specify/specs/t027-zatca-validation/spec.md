# T027 Specification

Malformed taxpayer and CSR inputs must be rejected locally before the ZATCA
SDK/provider path. A Saudi VAT number is exactly 15 digits and starts and ends
with `3`; required values cannot be blank or whitespace-only; and the CSR
location uses the Saudi National Address short-address shape of four letters
followed by four numbers. Valid existing taxpayer fixtures remain accepted.

This feature does not alter onboarding state transitions, persistence schema, or
OTP behavior.
